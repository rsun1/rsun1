### [TPV Anomaly Explainer](https://github.com/rsun1/TPV-Anomaly-Explainer)
Automated payment anomaly detection with LLM-driven root cause narration.

Prophet-based detection with multiplicative seasonality across 4 payment 
products. Dimensional decomposition surfaces which merchant category, 
geography, payment method, or customer segment drove the anomaly. 
LLM synthesizes a ranked root cause narrative from the decomposition output.

Two-layer eval: detection recall scored against labeled ground-truth 
injection events, and LLM-as-judge scoring each narrative on hypothesis 
accuracy, evidence specificity, and actionability.

**Final eval: 92% detection recall · 82% attribution accuracy · 4.1/5 narrative score**

`Python` `Prophet` `FastAPI` `React` `PostgreSQL`
